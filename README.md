# WorkflowHub

A full-stack workflow management system for creating, assigning, tracking, and reviewing tasks.

## 🚧 Project Status

**Currently in development**

This project is being developed to explore full-stack application development, RESTful APIs, relational database design, authentication, and modern frontend development.

## 🎯 Objective

WorkflowHub is designed to provide a centralized platform where teams can manage projects and tasks through structured workflows.

The system will allow users to:

- Create and manage projects
- Create and assign tasks
- Track task progress
- Review and update task status
- Collaborate through comments
- Manage users and roles
- Monitor workflow activity through dashboards
